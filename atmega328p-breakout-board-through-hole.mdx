A circuit on a breadboard works on the desk and fails when you move it: a jumper wire falls out, a loose contact adds noise, and nobody can build the same circuit twice. A printed circuit board (PCB) fixes the wiring in copper, so the circuit can be carried, copied and given to another person. In this lesson you design your first board in KiCad 9, from an empty project to a board that blinks a light. The board carries an ATmega328P (the chip of the Arduino Uno) with its power supply, clock, reset button and programming connectors. Every part has wire legs that pass through holes in the board (through-hole parts), the easiest kind to solder. The lesson is long, so each main section ends at a point where you can save your work and stop. #KiCad #ATmega328P #PCBDesign

A board design is two drawings of one circuit. The **schematic** shows which pin connects to which pin, with no regard for size or position. The **layout** shows where each part sits and where each copper track runs. You draw the schematic first because a wiring mistake costs a minute to correct there and a new board to correct in copper. KiCad carries the connections from the first drawing to the second, checks both, and writes the files a factory needs.

```text
 1 Schematic    2 Layout       3 Checks       4 Files
 ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
 │ symbols, │   │footprints│   │ ERC, DRC │   │ Gerber,  │
 │ wires    ├──►│ tracks   ├──►│ no errors├──►│ drill    │
 └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

## What We Are Building

<Card title="ATmega328P Breakout Board" icon="star">
A small, complete microcontroller board: an ATmega328P in a 28-pin socket, a 16 MHz crystal, a 5 V regulator, two programming connectors, a power LED, a user LED, a reset button, and two rows of sockets that bring out every input and output pin. Because the chip sits in a socket, you can program it here and move it to another circuit.

## Schematic Capture

<InArticleAd />


The schematic says which parts are on the board and how they connect. Each part is drawn as a **symbol**, a small picture with numbered pins. Every group of pins that are joined together is a **net**, and a net can carry a name such as `+5V` or `RESET`. Two wires with the same name are connected even when no line joins them on the sheet, which keeps a large drawing free of crossing lines.

The board is seven small circuits. Build them one at a time, and save after each.

<LinkButton href="https://github.com/SiliconWit/pcb-design-kicad/blob/main/schematics/atmega328p-breakout-board-through-hole.pdf" target="_blank" variant="secondary" icon="document">Download Schematic PDF</LinkButton>

### Power Supply

The chip needs a steady 5 V. A wall adapter gives 7 to 12 V that is not steady, and one day somebody will connect it the wrong way round. So this circuit does three jobs:

- Diode D3 passes current in one direction only, so a reversed supply is blocked and nothing is damaged.
- Regulator U2 (LM7805) turns the 7 to 12 V into 5 V and loses the difference as heat.
- Capacitors C5 and C6 store a little charge beside the regulator, which keeps its input and output steady when the load changes.

The net between the diode and the regulator is named `VIN`. It goes to a socket pin, for outside circuits that need the higher voltage.

```text
 J1 tip   ●──┬──►|──┬── VIN ──┤IN   U2   OUT├──┬── +5V
 J6 pin 1 ●──┘  D3  │         │   LM7805    │  │
                   ─┴─        └──────┬──────┘ ─┴─
                C5 ─┬─ 10uF          │     C6 ─┬─ 10uF
 J1 sleeve ●──┬─────┴────────────────┴─────────┴── GND
 J6 pin 2  ●──┘
```

<Steps>
1. **Place the barrel jack.** Press `A` (Add Symbol), search for `Barrel_Jack_Switch`, and place it on the left of the sheet. Its pins are:
   - Pin 1, **Tip**: the inner contact, positive on most adapters
   - Pin 2, **Sleeve**: the outer contact, ground
   - Pin 3, **Switch**: a contact that opens when a plug is inserted. It is not used here. Press `Q` and click pin 3 to mark it "no connect", or the electrical rules check (ERC) will report an open pin.

2. **Place the protection diode.** Add `D_Schottky` (D3, 1N5817) with its anode to the jack tip and its cathode toward the regulator. A Schottky diode is used because it loses only about 0.3 V when it conducts, so the regulator still receives enough voltage.

3. **Place the regulator.** Add `LM7805_TO220` (search for `7805`) to the right of the jack.

4. **Place the capacitors.** Add two `C_Polarized` symbols: C5 (10uF) from the regulator input to ground, and C6 (10uF) from the regulator output to ground. The LM7805 data sheet recommends a capacitor on each side for stable operation.

5. **Add the power symbols.** Press `P` (Add Power Port) and place `+5V` on the regulator output and `GND` on the ground wire.

6. **Name the VIN net.** KiCad has no `VIN` power symbol. Draw the wire from the diode cathode to the regulator input, press `Ctrl+L` (Add Global Label), type `VIN`, and drop the label on that wire. A second `VIN` label anywhere else (at the J4 pin, for example) joins the same net.

7. **Add the screw terminal (J6).** Not everyone has an adapter with a barrel plug. Press `A`, search `Screw_Terminal_01x02` (or `Conn_01x02`), and place it near J1. Because J6 connects before D3, both inputs are protected against a reversed supply.

8. **Draw the wires.** Press `W` and connect:
   - J1 Tip and J6 pin 1 to the D3 anode
   - D3 cathode to C5 positive and to the regulator input (the `VIN` net)
   - Regulator output to C6 positive and to `+5V`
   - J1 Sleeve, J6 pin 2, C5 negative, the regulator GND pin and C6 negative to `GND`
</Steps>

:::tip[Running the board from 5 V]
A regulated 5 V supply (a USB power bank, a bench supply) can feed the board through the `+5V` and `GND` pins of J4. Two cautions:

- Disconnect any 7-12V source first, or the two supplies will both try to set the +5V net.
- This path does not pass through D3. A reversed 5 V supply will destroy the chip, so check the polarity with a meter before you connect it.
:::

:::note[If ERC says VIN has no source]
ERC cannot see the wall adapter, so it may report that nothing drives `VIN`. Add a `PWR_FLAG` symbol to the `VIN` net. The flag tells ERC that the net is fed from outside the sheet. It changes nothing electrically.
:::

### MCU and Crystal

The microcontroller (MCU) needs three small circuits around it to run correctly:

- **A crystal with two load capacitors.** The crystal is the clock: it sets the speed at which the chip executes instructions, 16 million steps a second here. The two 22 pF capacitors are the load the crystal maker specifies. Without them the frequency is wrong or the clock does not start.
- **A decoupling capacitor at each supply pin.** A digital chip takes its current in short, sharp pulses. A track is too slow to deliver such a pulse from a regulator several centimetres away, so the voltage at the pin dips and the chip can reset or misread. A 100nF capacitor beside the pin is a small local store of charge that supplies the pulse.
- **A capacitor on AREF**, the reference voltage of the analog-to-digital converter, which keeps noise out of analog readings.

```text
   XTAL1 ──┬── ┌────────┐ ──┬── XTAL2
           │   │   Y1   │   │
           │   │ 16MHz  │   │
           │   └────────┘   │
          ─┴─              ─┴─
       C1 ─┬─ 22pF      C2 ─┬─ 22pF
           │                │
          GND              GND
```

```text
       +5V                       +5V
        │                         │
        ├── VCC (pin 7)           ├── AVCC (pin 20)
        │                         │
       ─┴─                       ─┴─
    C3 ─┬─ 100nF              C4 ─┬─ 100nF
        │                         │
       GND                       GND

   AREF (MCU pin 21) ──┬──
                      ─┴─
                   C7 ─┬─ 100nF
                       │
                      GND
```

All `+5V` symbols are one net and all `GND` symbols are one net, so electrically the capacitors could be drawn anywhere on the sheet. Drawing C3 at pin 7 and C4 at pin 20 records where they must sit on the board.

The texts `VCC (pin 7)` and `AVCC (pin 20)` in the drawing only say which pin is meant. Do not add them as net labels: the wire is already named `+5V`, and a second name gives a `multiple_net_names` warning in ERC.

<Steps>
1. **Place the ATmega328P.** Search the symbol library for `ATmega328P-P` and place it in the center of the sheet. The `-P` means the 28-pin through-hole package (DIP-28). The order code `ATmega328P-PU` is the same part.

2. **Connect the power pins.** Wire `VCC` (pin 7) and `AVCC` (pin 20) to `+5V`, and `GND` (pin 8) to `GND`. The second ground pin (pin 22) is hidden in the symbol and joins the `GND` net by its name. **View > Show Hidden Pins** shows it.

3. **Place the decoupling capacitors.** Add two `C` symbols of 100nF: C3 from VCC to `GND` and C4 from AVCC to `GND`.

4. **Place the crystal.** Add `Crystal` and connect it between XTAL1 (pin 9) and XTAL2 (pin 10).

5. **Place the load capacitors.** Add two `C` symbols of 22pF: C1 from XTAL1 to `GND` and C2 from XTAL2 to `GND`.

6. **Filter AREF.** Add a `C` symbol (C7, 100nF) from AREF (pin 21) to `GND`.
</Steps>

### Reset Circuit

RESET is an input that restarts the chip when it is pulled to 0 V. A pin left unconnected picks up noise, and the chip would restart at random. R1 holds RESET at 5 V, and SW1 connects it to ground while you press it. With 10k, pulling the pin low takes only 0.5 mA (5 V / 10k), which the button, the programmer and the serial cable can all do.

```text
       +5V
        │
       ┌┴┐
    R1 │ │ 10k
       └┬┘
        ├──► RESET  (MCU pin 1, ISP pin 5)
       ┌┴┐
   SW1 │•│ (push to short)
       └┬┘
        │
       GND
```

<Steps>
1. **Place the pull-up resistor.** Add `R` (10k, R1) from the RESET pin (pin 1) to `+5V`.

2. **Place the reset button.** Add `SW_Push` from RESET to `GND`.

3. **Name the RESET net.** Press `Ctrl+L`, type `RESET`, and drop the label on the wire that joins R1, pin 1 and SW1. You will place the same label at the ISP header (J2 pin 5) and at capacitor C8, and all of them join one net with no crossing wires.
</Steps>

### ISP Programming Header

A new chip is empty. ISP (in-system programming) writes a program into the chip through four signal pins while the chip sits on the board. This 6-pin header carries those signals, with power and ground, to a programmer such as a USBasp or an Arduino that acts as one. The same header sets the fuses (the chip's lasting settings, such as its clock source) and writes a bootloader.

```text
   J2 (AVR ISP, 2x3)
        ┌────┐
   MISO ┤1  2├ VCC
    SCK ┤3  4├ MOSI
  RESET ┤5  6├ GND
        └────┘
```

<Steps>
1. **Place a 2x3 connector.** Add `AVR-ISP-6` from the `Connector` library. Its pins are already named. If you cannot find it, use `Conn_02x03_Odd_Even` and name the pins yourself.

2. **Wire the ISP signals:**
   - Pin 1 (MISO) to PB4 (pin 18)
   - Pin 2 (VCC) to `+5V`
   - Pin 3 (SCK) to PB5 (pin 19)
   - Pin 4 (MOSI) to PB3 (pin 17)
   - Pin 5 (RESET): a `RESET` global label (`Ctrl+L`) on this pin's wire
   - Pin 6 (GND) to `GND`
</Steps>

### FTDI Programming Header

This second connector loads programs from a common USB-to-serial cable (FTDI, CP2102 or CH340), as an Arduino Uno does. It works only after a bootloader has been written through the ISP header. A bootloader is a small program that runs first after each reset and receives new code over the serial pins.

The cable's DTR line resets the chip at the start of each upload, so the bootloader runs at the right moment. DTR reaches RESET through capacitor C8. A capacitor passes a change of voltage as a short pulse and blocks a steady level, so the chip restarts once and is not held in reset.

```text
   J5 (FTDI cable)
   ┌─────────────┐
   │ 1  GND      ├─────────────► GND
   │ 2  CTS      ├─────────────► GND
   │ 3  VCC      ├─────────────► +5V
   │ 4  TXD      ├─────────────► PD0/RXD (pin 2)
   │ 5  RXD      ├─────────────► PD1/TXD (pin 3)
   │ 6  DTR      ├──┤├──────────► RESET (pin 1)
   └─────────────┘  C8
                    100nF
```

<Steps>
1. **Place a 1x6 connector.** Add `Conn_01x06_Pin` for J5. The pin order is that of the common FTDI cable.

2. **Place the reset capacitor.** Add a `C` symbol (C8, 100nF) between J5 pin 6 (DTR) and the RESET net.

3. **Wire the FTDI signals:**
   - Pin 1 (GND) to `GND`
   - Pin 2 (CTS) to `GND`. Some cables do not send data while this pin is left open.
   - Pin 3 (VCC) to `+5V`
   - Pin 4 (TXD, output of the cable) to PD0/RXD (pin 2)
   - Pin 5 (RXD, input of the cable) to PD1/TXD (pin 3)
   - Pin 6 (DTR) through C8 to a `RESET` global label
</Steps>

The data lines cross: what the cable transmits, the chip receives.

### LEDs

The power LED shows that the +5V net is alive. The user LED is on PB5, the pin an Arduino program calls `D13`, so any "blink" program lights it. An LED needs a resistor in series, or it takes too much current and burns out. With 330 ohms the current is about 9 mA: 5 V less the 2 V across the LED leaves 3 V, and 3 V / 330 ohms is 9 mA.

```text
   Power LED                 User LED

       +5V                       PB5
        │                         │
       ┌┴┐                       ┌┴┐
    R2 │ │ 330                R3 │ │ 330
       └┬┘                       └┬┘
       ┌┴┐                       ┌┴┐
    D1 │▼│ (green)            D2 │▼│ (red)
       └┬┘                       └┬┘
        │                         │
       GND                       GND
```

<Steps>
1. **Power LED.** Add `LED` (D1) and `R` (R2, 330). Connect `+5V` to R2, R2 to the D1 anode, and the D1 cathode to `GND`.

2. **User LED.** Add `LED` (D2) and `R` (R3, 330). Connect PB5 (pin 19) to R3, R3 to the D2 anode, and the D2 cathode to `GND`. PB5 is also the ISP clock (SCK, J2 pin 3), so this LED flickers while a program is being written. That is normal.
</Steps>

### I/O Pin Headers

A chip in a socket in the middle of a board is hard to reach. Two rows of sockets at the board edges bring every usable pin, and the power nets, to where a jumper wire can plug in.

| Pin | J3 | J4 |
|-----|----|----|
| 1 to 6 | PD0 to PD5 | PC0 to PC5 |
| 7 | PD6 | AREF |
| 8 | PD7 | +5V |
| 9 | PB0 | RESET |
| 10 | PB1 | VIN |
| 11 | PB2 | +5V |
| 12 | PB3 | GND |
| 13 | PB4 | +5V |
| 14 | PB5 | GND |

<Steps>
1. **Place two 1x14 connectors.** Add `Conn_01x14_Pin` for J3 and J4, one at the left and one at the right of the sheet.

2. **Wire J3** to PD0-PD7 (chip pins 2-6 and 11-13) and PB0-PB5 (chip pins 14-19).

3. **Wire J4** to PC0-PC5 (chip pins 23-28), then AREF, `+5V`, RESET, VIN, and the power pins in the order of the table.
</Steps>

PB6 and PB7 (chip pins 9 and 10) do not go to a socket because the crystal uses them.

### Make the Schematic Readable

Another person, or you in six months, must be able to read this sheet. Two small things help.

**Draw a named box around each circuit.** Use **Place > Draw Text Box**, type the name ("Power Supply", "Reset" and so on), click **OK**, then click two corners. The boxes have no electrical effect.

**Fill in the title block.** Open **File > Page Settings** and enter the title, the date and a revision (`A`). Change the revision each time you change the schematic and export new factory files, so that two versions of the board on your desk can be told apart.

### Assign Component Values

A symbol does not yet say which resistor or capacitor it is. Give every part its value:

<Steps>
1. Double-click each component to open its properties.

2. Set the **Value** field:
   - C1, C2: `22pF`
   - C3, C4, C7, C8: `100nF`
   - C5, C6: `10uF`
   - R1: `10k`
   - R2, R3: `330`
   - Y1: `16MHz`
   - D3: `1N5817`

3. **Prepare for the electrical rules check (ERC).** ERC reads the schematic and reports connections that cannot be right: a pin left open, two outputs joined, a supply net that nothing feeds. Four things cause most of its first reports:
   - **Supply nets fed from outside.** Place a `PWR_FLAG` symbol on `VIN` and one on `GND`, or ERC reports `power_pin_not_driven`. Do not place one on `+5V`: the regulator output already feeds that net, and a flag there gives a `pin_to_pin` error.
   - **Pins left open on purpose.** Press `Q` and click each one (J1 pin 3), or ERC reports `pin_not_connected`.
   - **A global label used once.** A label joins nets only if the same name appears at both ends. A single label gives `global_label_dangling`.
   - **Capital and small letters.** `PC0` and `pc0` are two different nets. Use capitals everywhere.

4. Open **Inspect > Electrical Rules Check** and click **Run ERC**. Correct every error before you continue.
</Steps>

ERC checks the connections, not the design. A 22uF capacitor typed where 22pF belongs passes ERC, so read each value once more.

### Assign Footprints

A symbol has no size. The **footprint** is the pattern of copper pads and holes that one real part needs on the board: the right number of holes, of the right diameter, at the right spacing. With a wrong footprint the part does not fit the finished board, and no check in KiCad will tell you, because KiCad has never seen the part.

Open **Tools > Assign Footprints** and give each symbol the footprint in the table. When you choose for your own designs, turn on **Filter by symbol** in that dialog: the list of thousands of footprints falls to the few that suit the symbol. Then compare the footprint with the drawing in the part's data sheet.

## PCB Layout

<InArticleAd />


The schematic says what connects to what. The layout decides where each part sits and where each copper track runs, and those choices decide whether the circuit works well. A decoupling capacitor on the far side of the board is connected correctly and does almost nothing.

A two-layer board has copper on its top face (KiCad calls it `F.Cu`, front copper) and on its bottom face (`B.Cu`). The parts sit on top, and their legs pass through holes and are soldered.

### Import Netlist

The list of all parts and nets is called the netlist. KiCad passes it from the schematic to the board, so you never draw a connection twice.

<Steps>
1. In the Schematic Editor, run **Tools > Update PCB from Schematic** (or press `F8`). Click **Update PCB**, then **Close**. The PCB Editor opens with every footprint. Thin straight lines join the pads that belong to one net. These lines show what you still have to connect with copper.

2. The footprints arrive in one pile. Click to drop them near the center of the sheet.
</Steps>

### Define Board Outline

The outline is the shape the factory cuts. This board is 66 mm wide and 53 mm tall, with 3 mm rounded corners that do not catch on fingers or cables, and four holes for M3 screws so it can be fixed in a box.

```text
 ╭──────────────────────────────────────────────────────╮
 │ ⊕  D1   ┌────────── J4 (1x14) ──────────┐          ⊕ │
 │┌────┐     D3   Y1   C1  C2   R3  D2          ┌────┐  │
 ││ J1 │                                        │ J2 │  │
 │└────┘   ┌──────────────────────────────┐     └────┘  │
 │┌────┐   │   U1 ATmega328P in socket    │     ┌────┐  │
 ││ J6 │   └──────────────────────────────┘     │ J5 │  │
 │└────┘     R2    C3   C4   C7   C8            │    │  │
 │  SW1    ┌────┐                               └────┘  │
 │         │ U2 │   R1          C5   C6                 │
 │ ⊕       └────┘ ┌────────── J3 (1x14) ──────────┐   ⊕ │
 ╰──────────────────────────────────────────────────────╯
```

The drawing shows the finished placement, seen from above. The marks ⊕ are the mounting holes.

<Steps>
1. **Select the Edge.Cuts layer** in the Layers panel on the right. Whatever you draw on this layer is the cut line.

2. **Draw the rectangle.** Use **Place > Draw Rectangle**. Click the first corner at (0, 0) and the opposite corner at (66, 53). You can type the numbers in the X/Y fields at the bottom of the editor, or set the grid to 1 mm.

3. **Round the corners.** Right-click the rectangle, choose **Shape Modifications > Fillet Lines**, and set the radius to **3 mm**.

4. **Add four M3 mounting holes.** Open **Place > Add Footprint** (or press `A`) and search for `MountingHole_3.2mm_M3`. Place one 6 mm in from the edges at each corner: (6, 6), (60, 6), (6, 47) and (60, 47). That leaves about 4.4 mm of board around each hole, enough that the board does not crack when the screw is tightened.

5. **Optional: add text.** Use **Place > Draw Text** on the `F.SilkS` layer (the printed white text of the board) to write the board name and revision.
</Steps>

### Component Placement

Placement decides how easy the routing is and how well the board works. Place every part before you draw any track. Three rules explain most of the positions below: connectors go at the edges where a cable can reach them, parts that work together sit together, and each decoupling capacitor sits beside the pin it serves.

<Steps>
1. **Sockets J4 and J3** along the top and bottom edges. At 2.54mm pin spacing they accept jumper wires.

2. **ATmega328P (U1)** in its socket, centered between J3 and J4. Orient it so pin 1 is at the top-left.

3. **Barrel jack (J1)** on the upper-left edge, so the plug enters from outside the board.

4. **Screw terminal (J6)** below J1 on the left edge, where wires can reach it.

5. **Protection diode (D3)** along the top, between J1 and the crystal, on the path from the input to the regulator.

6. **Regulator (U2)** at the bottom-left, with **C5 and C6** at the bottom-right on the same supply nets.

7. **Crystal and load capacitors (Y1, C1, C2)** above U1. The clock signal is weak and picks up noise easily, so the tracks to XTAL1 and XTAL2 must be short.

8. **Decoupling capacitors (C3, C4, C7)** in a row below U1, each as close as possible to VCC, AVCC and AREF.

9. **ISP header (J2)** at the top-right and **FTDI header (J5)** on the right edge, where a cable can plug in. **C8** goes in the row of capacitors, on the way from DTR to RESET.

10. **Reset button (SW1)** at the left, below J6, where a finger can reach it.

11. **LEDs and resistors:** D1 (power, green) at the top-left corner with R2 in the row below U1. D2 (user, red) with R3 at the top, right of the crystal. R1 in the bottom row.
</Steps>

### Design Rules

A design rule is a limit that you give to KiCad: the narrowest track, the smallest gap between two pieces of copper, the smallest hole. Every way of making a board has such limits. Below them, tracks break or touch each other. KiCad gives each new track its width from the rules and reports anything that breaks them, so set the rules before you route. The values below are wide enough for home etching and milling, the roughest of the three ways this board can be made.

<Steps>
1. Open **File > Board Setup...** in the PCB Editor. In the dialog, expand **Design Rules** and click **Net Classes**. A net class is a group of nets that share the same rules.

2. Set the **Default** net class. Only the first four columns matter here:
   - **Clearance:** `0.3 mm`, the smallest gap between two pieces of copper. A factory can make 0.13 mm, but a gap this narrow often bridges on a board etched at home.
   - **Track Width:** `0.5 mm`. A signal track carries a few milliamperes and could be far narrower. The width is for strength: a wide track survives etching and soldering.
   - **Via Size:** `0.8 mm` and **Via Hole:** `0.4 mm`. A via is a small hole that joins a track on the top to a track on the bottom. These are the pad diameter and the drill diameter.

   Leave the other columns as they are. They are for boards with laser-drilled holes and for fast signal pairs.

3. Add a **Power** net class for `+5V` and `GND`:
   - **Clearance:** `0.3 mm`
   - **Track Width:** `0.8 mm`. All the current of the board passes along these tracks, and a wider track has less resistance. At 0.5 A, 100 mm of 0.8 mm track loses about 30 mV. The same length of 0.2 mm track loses about 120 mV.

4. Click **OK**.
</Steps>

The **Constraints** page of the same dialog holds the absolute minimums that the design rules check will report. Leave it as it is for this board. You change it when a factory gives you its own limits.

### Routing

Routing is drawing the copper tracks that replace the thin lines between pads.

**Which layer.** Route on **B.Cu (bottom copper)** and use **F.Cu (top copper)** only to cross over a track that is in the way. The legs of the parts are soldered on the bottom, so that is where the tracks are most useful. A through-hole pad has copper on both faces, so a track can change layer at any pad. A separate via is needed only when a track must change layer between two pads.

<Steps>
1. **Route the supply nets first, on B.Cu.** Click **B.Cu** in the **Layers** panel to make it active. Open **Route > Route Single Track** (or press `X`) and click from pad to pad. Connect all `+5V`, `VIN` and `GND` pads. These tracks take the 0.8 mm width of the Power net class.

2. **Route the crystal.** Keep the XTAL1 and XTAL2 tracks short, and let no other signal run between them or beside them.

3. **Route the programming signals.** MISO, MOSI, SCK and RESET to the ISP header. Then RXD (PD0) and TXD (PD1) to J5, and DTR through C8 to RESET.

4. **Route the remaining signals:** the LEDs, the reset button and the two sockets. The router moves existing tracks aside to make room.

5. **Cross a track with a via.** When the track you are drawing must cross one that is already there:
   - Press `V`, then left-click to place a via at the cursor.
   - The router continues on F.Cu (the preview turns from blue to red) and passes over the other track.
   - Left-click the pad where the track ends.

   The next track you start is on B.Cu again. Two or three vias are normal for this board. `Ctrl+Z` removes the last piece of track.

6. **Add a ground pour on both layers.** A pour fills all the unused area of a layer with copper that is connected to `GND`. Every part then has a short, wide path back to ground, which lowers noise. For home etching it also leaves less copper to dissolve.
   - Click **F.Cu** in the Layers panel. Open **Place > Draw Filled Zones** (or press `Ctrl+Shift+Z`).
   - Click the first corner of the board outline. In the dialog, set **Net** to `GND` and click **OK**.
   - Click the other three corners, and double-click to close the shape.
   - Open **Edit > Fill All Zones** (or press `B`).
   - Do the same with **B.Cu** active.

7. **Run the design rules check (DRC).** DRC compares the board with your rules and with the schematic. Open **Inspect > Design Rules Check** and click **Run DRC**. The usual reports are:
   - a pad with no track (you missed a connection)
   - a clearance error (two pieces of copper too close)

   Correct them until DRC shows no errors and no unconnected items.
</Steps>

### 3D Preview

The flat view does not show height, or a connector that faces the wrong way.

<Steps>
1. Open **View > 3D Viewer** (or press `Alt+3`) and turn the board.

2. Check four things:
   - Is every part on the top face?
   - Does the barrel jack open toward the board edge?
   - Do the sockets and headers stand clear of taller parts?
   - Can a finger reach the reset button?
</Steps>

The layout is complete, and this is a good place to stop.

## Manufacturing

<InArticleAd />


The same KiCad files can become a real board in three ways. Choose the one that suits your tools, your money and your time.

| Path | Cost | Lead time | Tools needed |
|------|------|-----------|--------------|
| **Order from a fab** (JLCPCB, OSHPark, PCBWay) | ~2-10 USD for 5 boards | 1-2 weeks shipping | None |
| **CNC mill** the board yourself | One-time machine cost | ~1 hour per board | CNC mill with isolation routing |
| **Home etch** (toner transfer) | A few cents per board | ~2 hours per board | Laser printer, ferric chloride, drill |

A factory makes holes with copper inside them (plated holes), so the top and bottom copper are joined at every pad and via. A milled or etched board has bare holes. On such a board you join the two faces yourself, as Path B and Path C describe.

### Generate Manufacturing Files

A factory does not open a KiCad project. It works from **Gerber files**, a format every board maker reads: one file for each layer, each a flat picture of where the copper, the protective coating (solder mask) or the printed text goes. A separate **drill file** lists the position and diameter of every hole.

<Steps>
1. **Export the Gerbers.** Go to **File > Plot**. Select these layers: `F.Cu`, `B.Cu`, `F.SilkS`, `B.SilkS`, `F.Mask`, `B.Mask`, `Edge.Cuts`. Set the output format to **Gerber**. Leave **Mirrored** unchecked. Click **Plot**. KiCad writes one `.gbr` file for each layer to the project's `gerbers/` folder.

2. **Generate the drill file.** In the same dialog, click **Generate Drill Files**. Select **Excellon** format and **PTH and NPTH in single file** (plated and unplated holes together). Click **Generate Drill File**.

3. **For a factory: zip the files.** Put all the `.gbr` and `.drl` files in one `.zip` archive.

4. **For home etching: also export the copper as PDF.** Open **File > Plot** again, set the format to **PDF**, and select `F.Cu` and `B.Cu`. Check **Mirrored** for `F.Cu` only. The printed sheet is laid face down on the copper, so the top layer must be printed as a mirror image to come out the right way round.
</Steps>

### Path A: Order from JLCPCB (or any fab house)

This is the best path for a first board: the least work and the fewest mistakes. Five two-layer boards cost about 2 USD plus shipping.

<Steps>
1. Go to [jlcpcb.com](https://jlcpcb.com), click **Order Now**, and upload the zip file.

2. Check what the site has read from your files: **Layers: 2**, **Dimensions: 66 x 53 mm**. Choose **Surface Finish: HASL**, the cheapest, which is good for hand soldering. Leave the other settings as they are.

3. Place the order. The boards arrive in one to two weeks.
</Steps>

### Path B: CNC Milling

A milling machine cuts a narrow channel around each track and leaves the copper between the channels. It uses no chemicals, but the machine must position its tool to better than 0.1 mm. The lesson on the [SMD sensor shield](/education/pcb-design-kicad/atmega328p-sensor-shield-smd-components/) covers milling in full. In short:

<Steps>
1. Convert the Gerbers to machine instructions (G-code) with [FlatCAM](http://flatcam.org/) or [pcb2gcode](https://github.com/pcb2gcode/pcb2gcode): one file for `F.Cu`, one for `B.Cu` and one for the holes.

2. Fix a double-sided copper board to the machine bed. First drill two alignment holes outside the outline, through the board and into the bed. With pins in these holes the second side lines up with the first.

3. Mill `B.Cu` and drill the holes. Turn the board over on the pins and mill `F.Cu`.

4. Join the two faces at each via: push a short bare wire through the hole, solder it on both sides and cut it flush.

5. Cut the board along its outline and sand the edges.
</Steps>

### Path C: Home Etching (Toner Transfer)

Printer toner resists the etching liquid, so copper under toner stays and the rest dissolves. This path is the cheapest and takes the most work.

<Steps>
1. **Print the copper layers** with a laser printer on glossy paper or toner transfer paper: `F.Cu` mirrored, `B.Cu` not mirrored. An inkjet printer does not work, because its ink does not transfer.

2. **Prepare a double-sided copper board.** Cut it to about 72 x 60 mm, a little larger than the outline. Clean both faces with fine sandpaper (400-600 grit) and isopropyl alcohol. Toner does not hold on a dirty surface.

3. **Transfer the top layer.** Lay the `F.Cu` print face down on the copper. Press a clothes iron at its hottest setting, without steam, firmly on it for about 5 minutes. Let it cool, soak it in warm water and peel the paper away. The toner stays on the copper.

4. **Drill the four M3 mounting holes.** They line up the second side with the first.

5. **Transfer the bottom layer.** Turn the board over, line up the `B.Cu` print with two pins through two of the holes, and iron it on in the same way.

6. **Etch.** Put the board in ferric chloride solution and move it gently. The bare copper dissolves in 10 to 30 minutes, on both faces at once.

7. **Clean.** Rinse the board with water and remove the toner with acetone or fine sandpaper.

8. **Drill the other holes:** 0.8 mm for part legs, 1.0 mm for the headers and the barrel jack. Drill straight down.

9. **Join the two faces** at each via with a short bare wire soldered on both sides.

10. **Cut the board** along its outline with a small saw and sand the edges.

11. **Inspect.** Repair a broken track with thin wire and solder. Scrape away any copper that bridges two tracks.
</Steps>

:::caution[Safety]
Ferric chloride stains permanently and attacks skin, eyes and metal. Wear gloves and eye protection, and work where the air moves. Never pour used solution down a drain. Follow your local rules for chemical waste.
:::

:::tip[Solder both sides of every pad on a home-made board]
On a milled or etched board, a pad with a track on the top face is joined to its track on the bottom face only by the part's leg. Solder the leg on **both** faces. A board from a factory does not need this, because its holes are plated.
:::

## Soldering and Assembly

<InArticleAd />


Solder the lowest parts first and the tallest last. The board then lies flat on the table, upside down, and holds each part in place while you solder it. Four parts work in one direction only and are marked in the list.

<Steps>
1. **The 28-pin socket.** Its notch marks the end where pin 1 is.

2. **Low parts.** Resistors (R1, R2, R3), ceramic capacitors (C1-C4, C7, C8), the crystal (Y1) and the diode (D3: the stripe is the cathode and must match the stripe printed on the board).

3. **Taller parts.** Electrolytic capacitors (C5, C6: the stripe marks the negative leg), LEDs (D1, D2: the longer leg is the anode), and the reset button (SW1).

4. **Connectors.** Barrel jack (J1), screw terminal (J6), ISP header (J2), FTDI header (J5) and sockets (J3, J4).

5. **Regulator.** Solder U2 (LM7805). It becomes hot when the input is 12V and the load is large, so add a small clip-on heatsink for that use.

6. **Do not insert the ATmega328P yet.** It goes in after the supply has been checked.
</Steps>

## First Power-On

<InArticleAd />


A wiring fault on a board connected to a supply or a battery can destroy parts in a second, and a shorted battery can burn. So check the board with a meter before it sees power, and power it the first time without the chip.

<Steps>
1. **Look.** Examine every solder joint with a magnifier. Look for solder that bridges two pins, and for dull, lumpy joints.

2. **Measure with no power connected.** Set a multimeter to continuity. Check that:
   - `+5V` and `GND` are not joined, and `VIN` and `GND` are not joined
   - `+5V` reaches socket pins 7 and 20
   - `GND` reaches socket pins 8 and 22

3. **Check the polarity of the supply** with the meter before you plug it in: the tip of the plug, or the wire to J6 pin 1, must be positive.

4. **Apply power with the socket empty.** Connect a 9V battery or a 7-12V supply. The power LED (D1) lights.

5. **Measure the voltage.** Between `+5V` and `GND`, and at socket pin 7, the meter must read 5.0V (±0.1V). If it does not, disconnect the supply at once and check D3 and U2.

6. **Remove the power and insert the ATmega328P.** The dot or notch on the chip goes to the notch of the socket.
</Steps>

## Firmware: Blink LED

<InArticleAd />


You now write a program into the ATmega328P through the ISP header, with no Arduino software and no bootloader. If the LED blinks, the supply, the clock, the chip and the output pin all work.

### Toolchain Setup

```

   ```

</TabItem>

### Blink Code

Save this as `blink.c`:

```c
/*
 * blink.c - Toggle LED on PB5 (pin 19) every 500ms
 * ATmega328P @ 16 MHz, no Arduino, no bootloader
 */

#define F_CPU 16000000UL

#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    DDRB |= (1 << PB5);   /* Set PB5 as output */

    while (1) {
        PORTB ^= (1 << PB5);  /* Toggle PB5 */
        _delay_ms(500);
    }
}
```

### Compile and Flash

Connect a USBasp programmer (or an Arduino that acts as an ISP programmer) to the 6-pin ISP header. Pin 1 of the cable goes to pin 1 of the header.

```bash
# Compile
avr-gcc -mmcu=atmega328p -DF_CPU=16000000UL -Os -o blink.elf blink.c
avr-objcopy -O ihex blink.elf blink.hex

# Set fuses for 16 MHz external crystal
avrdude -c usbasp -p m328p -U lfuse:w:0xFF:m -U hfuse:w:0xDE:m -U efuse:w:0xFD:m

# Flash the program
avrdude -c usbasp -p m328p -U flash:w:blink.hex:i
```

With an Arduino Uno as the programmer, replace `-c usbasp` with `-c stk500v1 -P /dev/ttyACM0 -b 19200` (use the port name of your system).

The red user LED (D2) now blinks once a second: 500ms on, 500ms off.

:::tip[What the three fuses set]
A new ATmega328P runs from a slow internal clock. The fuses tell it to use the crystal. They are written once and stay when a new program is written.

- `lfuse = 0xFF`: use the external crystal, with a 65 ms start-up delay. The Arduino Uno uses the same value.
- `hfuse = 0xDE`: keep ISP programming enabled, and reserve 512 bytes for a bootloader.
- `efuse = 0xFD`: hold the chip in reset when the supply falls below 2.7 V.
:::

### Optional: Burn a Bootloader for FTDI Uploads

For daily work the FTDI header is quicker than the ISP header: you load programs over a USB-serial cable with no programmer attached. For this the bootloader must first be written into the top 512 bytes of the chip's program memory. After each reset it waits a moment for new code on the serial pins, and if none comes it starts your program.

You write the bootloader once, with the ISP programmer:

```bash
# Download Optiboot (or use the copy in your Arduino install)
# Path on Linux: /usr/share/arduino/hardware/arduino/avr/bootloaders/optiboot/optiboot_atmega328.hex

avrdude -c usbasp -p m328p -U flash:w:optiboot_atmega328.hex:i
```

After this you can remove the ISP programmer and load programs with the Arduino IDE, PlatformIO or `avrdude -c arduino`:

```bash
avrdude -c arduino -P /dev/ttyUSB0 -b 115200 -p m328p -U flash:w:blink.hex:i
```

Keep both connectors in use: J5 for daily uploads, and J2 for the fuses, the bootloader, and a chip whose bootloader has been damaged.
